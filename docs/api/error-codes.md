# 错误码全表（Error Codes）

> 代码实现：`server/at-common/.../result/ErrorCode.java`（本文档与枚举保持一致，Java 为准）。
> 返回规则：无论 HTTP 状态如何，响应体恒为 `Result{code,message,data,traceId}`；前端以 `body.code` 为业务主判据。

## 编号分段

| 段 | 域 | HTTP 特征 |
| --- | --- | --- |
| `0` | 成功 | 200 |
| `1xxx` | 认证授权（含权限申请 / 授权冲突） | 401 / 403 / 400 · 200（流程提示） |
| `2xxx` | 参数校验 | 400 |
| `4xxx` | 文件 / 传输 | 200（分支）· 400 · 404 · 409 · 410 · 413 · 415 · 429 |
| `5xxx` | 系统异常 | 500 / 502 |

---

| 0 | `SUCCESS` | 200 | 成功 | 正常返回，读取 `data` |

## 1xxx：认证授权

| code | 枚举名 | HTTP | 中文提示 | 触发场景 / 前端行为 |
| --- | --- | --- | --- | --- |
| 1001 | `NOT_LOGIN` | 401 | 未登录或登录已过期 | 未携带 token 访问受保护接口；携带 token 跳登录 |
| 1002 | `TOKEN_EXPIRED` | 401 | 登录态已过期，请重新登录 | access token 过期；**静默**用 refresh token 换新并重放一次 |
| 1003 | `TOKEN_INVALID` | 401 | 登录态无效，请重新登录 | 伪造 / 签名错误 / 已吊销 token；refresh 失败时跳登录 |
| 1004 | `NO_AUTH` | 403 | 无操作权限 | 已登录但 RBAC 无权限点 / 数据范围不足；提示无权限不跳登录 |
| 1005 | `ACCOUNT_LOCKED` | 403 | 账号已锁定，请联系管理员 | 多次输错密码等触发锁定；提示联系管理员 |
| 1006 | `ACCOUNT_DISABLED` | 403 | 账号已被禁用，请联系管理员 | 账号被停用 / 冻结；提示联系管理员 |
| 1007 | `BAD_CREDENTIALS` | 401 | 账号或密码错误 | 登录鉴权失败（不区分“账号不存在”与“密码错误”）；清空密码框 |
| 1008 | `GRANT_ALREADY_ACTIVE` | 200 | 你已拥有该资源的有效授权 | 申请冲突校验命中：同资源已有生效授权；**流程提示码**，`data` 附现有授权信息，前端引导直接访问 |
| 1009 | `APPLICATION_DUPLICATE` | 200 | 您已有进行中的申请，请勿重复提交 | 申请冲突校验命中：同资源已有在审申请；**流程提示码**，`data` 附在审申请单 ID，前端跳转待办 |
| 1010 | `REASSIGN_INVALID` | 400 | 转审目标审批人无效或无权审批该资源 | 审批转审时目标审批人不存在 / 无权审批该资源；提示后重新选择审批人 |

## 2xxx：参数校验

| code | 枚举名 | HTTP | 中文提示 | 触发场景 / 前端行为 |
| --- | --- | --- | --- | --- |
| 2001 | `PARAM_ERROR` | 400 | 参数错误 | `@Valid` 校验失败兜底 / 业务自检失败；定位表单字段 |
| 2002 | `PARAM_MISSING` | 400 | 缺少必要参数 | 必填 Query / Form 参数缺失，`message` 附参数名 |
| 2003 | `PARAM_FORMAT_ERROR` | 400 | 参数格式不正确 | 邮箱 / 手机号 / 日期等格式非法 |
| 2004 | `PARAM_TYPE_ERROR` | 400 | 参数类型不匹配 | 路径参数类型错误 / 请求体 JSON 不可读 / 字段类型不符 |
| 2005 | `PARAM_OUT_OF_RANGE` | 400 | 参数超出允许范围 | 枚举值不存在、数值越界、长度超限 |

## 4xxx：文件 / 传输

### 上传链路：秒传 / 分片 / 完整性（4001~4003）

| code | 枚举名 | HTTP | 中文提示 | 触发场景 / 前端行为 |
| --- | --- | --- | --- | --- |
| 4001 | `INSTANT_UPLOAD_MISS` | 200 | 秒传未命中，请按分片上传 | 预检时服务端无相同 SHA-256 文件；**分支码**：`data` 附 `uploadId` 等上传票据，进入分片上传流程 |
| 4002 | `CHUNK_MISSING` | 200 | 分片缺失，请按服务端清单续传 | 续传 / 合并前发现缺片；**分支码**：`data` 附缺失分片清单，前端只传缺失片 |
| 4003 | `FILE_INTEGRITY_ERROR` | 409 | 文件完整性校验失败，请重新上传 | 重组后 SHA-256 与客户端上报不一致 / 分片不完整；提示重新上传 |

### 文件通用（4005~4009）

| code | 枚举名 | HTTP | 中文提示 | 触发场景 / 前端行为 |
| --- | --- | --- | --- | --- |
| 4005 | `FILE_NOT_FOUND` | 404 | 文件不存在或已被删除 | 详情 / 下载 / 恢复目标不存在；提示后刷新列表 |
| 4006 | `FILE_TOO_LARGE` | 413 | 文件大小超出限制 | 超过单文件上限（默认 10 GiB）；上传前本地预检 |
| 4007 | `FILE_TYPE_NOT_ALLOWED` | 415 | 文件类型不允许 | 扩展名 / MIME 命中黑名单；上传前本地预检 |
| 4008 | `FILE_UPLOAD_FAIL` | 400 | 文件上传失败，请稍后重试 | 分片落盘 / 存储异常；保留分片可续传 |
| 4009 | `FILE_DOWNLOAD_FAIL` | 400 | 文件下载失败，请稍后重试 | 读取 / 流式输出异常；重试或反馈 traceId |

### 外发分享（4004 / 4010~4012）

| code | 枚举名 | HTTP | 中文提示 | 触发场景 / 前端行为 |
| --- | --- | --- | --- | --- |
| 4004 | `SHARE_EXPIRED_OR_LIMIT` | 410 | 外发链接已过期或下载次数用尽 | 链接超期 / 下载次数耗尽；展示“链接已失效”，通知创建者（站内） |
| 4010 | `SHARE_CODE_ERROR` | 403 | 提取码错误 | 提取码不正确；剩余机会提示（连续错误会触发 4011） |
| 4011 | `SHARE_LOCKED` | 429 | 提取码错误次数过多，链接已临时锁定 | 连续错误达阈值（默认 5 次）临时锁定 30 分钟；通知链接创建者 |
| 4012 | `SHARE_REVOKED` | 410 | 外发链接已被撤销 | 创建者主动撤销后访问；展示“链接已失效” |

### 传输任务（410x）

| code | 枚举名 | HTTP | 中文提示 | 触发场景 / 前端行为 |
| --- | --- | --- | --- | --- |
| 4101 | `TRANSFER_TASK_NOT_FOUND` | 404 | 传输任务不存在 | 任务被清理 / ID 错误；刷新任务列表 |
| 4102 | `TRANSFER_STATE_ERROR` | 409 | 当前传输状态不允许该操作 | 对已完成任务执行开始、对进行中任务执行合并等状态冲突；按状态机约束交互 |
| 4103 | `TRANSFER_LIMIT_EXCEEDED` | 429 | 超出传输并发或流量限制 | 并发上传数 / 流量超限；退避后重试 |

## 附录 A：HTTP 状态使用约定

| HTTP | 何时出现 | 前端处理 |
| --- | --- | --- |
| 200 | 成功（code=0）或流程分支（4001 / 4002 / 1008 / 1009） | 按 `body.code` 分流 |
| 400 | 参数错误 2xxx / 1010（转审目标无效） | 定位并提示表单 / 请求参数 |
| 401 | 1001 / 1002 / 1003 / 1007 | 刷新令牌（1002）或跳登录 |
| 403 | 1004~1006 / 4010 | 无权限 / 凭证不对，不跳登录 |
| 404 | 4005 / 4101 | 资源不存在提示 |
| 409 | 4003 / 4102 | 状态冲突，刷新后重试 |
| 410 | 4004 / 4012 | 外发链接已不可用 |
| 413 | 4006 | 文件超限 |
| 415 | 4007 | 类型不允许 |
| 429 | 4011 / 4103 | 限流 / 锁定，退避重试 |
| 500 / 502 | 5xxx | 提示稍后重试，附 traceId 上报 |
