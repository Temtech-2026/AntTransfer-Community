# 🎫 错误码全表（Error Codes）

> 💻 代码实现：`server/at-common/.../result/ErrorCode.java`（本文档与枚举保持一致，Java 为准）。
> 📦 返回规则：无论 HTTP 状态如何，响应体恒为 `Result{code,message,data,traceId}`；前端以 `body.code` 为业务主判据。

## 🧭 一、编号分段

| 段 | 域 | HTTP 特征 |
| --- | --- | --- |
| `0` | 成功 | 200 |
| `1xxx` | 认证授权（含权限申请 / 授权冲突） | 401 / 403 / 400 · 200（流程提示） |
| `2xxx` | 参数校验 | 400 |
| `4xxx` | 文件 / 传输 | 200（分支）· 400 · 404 · 409 · 410 · 413 · 415 · 429 |
| `5xxx` | 系统异常 | 500 / 502 |

## 🗂️ 二、处理策略分类（按具体情况具体分析）

> 同一个 HTTP 状态可能对应完全不同的前端行为，因此**按「前端该做什么」**而非按数字分段划分策略。
> 下表策略代号将贯穿后续每张错误码表（「策略」列）与 `ErrorCode` 枚举注释，前端可据此写统一拦截器。

| 策略 | 名称 | 判定特征 | 前端标准动作 | 是否可原样重放 |
| --- | --- | --- | --- | --- |
| **A** | 成功 | `code=0` | 读取 `data` 正常渲染 | — |
| **B** | 流程分支 | `code≠0` 但 HTTP 200 | **不提示错误**，按 `data` 走业务分支（进入上传 / 按清单续传 / 直接访问 / 跳待办） | 是（由分支逻辑决定） |
| **C** | 凭证失效 | HTTP 401 | `1002` → 静默 refresh 后重放**一次**；其余 → 跳登录并清空令牌 | 仅 `1002` 可（且仅一次） |
| **D** | 拒绝且不跳登录 | HTTP 403 | 就地提示（无权限 / 已锁定 / 已禁用 / 提取码错误），**禁止**引导登录 | 否 |
| **E** | 请求需修正 | HTTP 400 / 404 / 413 / 415 | 定位到具体字段或资源后提示；修正后由用户重新发起 | 否（部分可重试，见 §四） |
| **F** | 状态失效 / 冲突 | HTTP 409 / 410 | 提示「状态已变化 / 已失效」，刷新列表或任务状态后重试 | 否（须先刷新状态） |
| **G** | 限流 / 锁定 | HTTP 429 | 提示被限流或已锁定，按退避策略（指数退避 / 等待解锁时刻）重试 | 是（退避后） |
| **H** | 系统兜底 | HTTP 500 / 502 | 统一提示「系统繁忙，请稍后重试」并展示 `traceId` 供上报 | 视接口幂等性而定 |

> ⚠️ **前端红线**：`5xxx` 与 `B` 类以外的错误，**禁止把服务端 `message` 当技术细节展示**；
> `message` 是给用户看的文案，技术排查一律用 `traceId`。

## ✅ 三、错误码明细

### 0：成功（策略 A）

### 🔐 1xxx：认证授权

| code | 枚举名 | HTTP | 策略 | 中文提示 | 触发场景 / 前端行为 |
| --- | --- | --- | --- | --- | --- |
| 1001 | `NOT_LOGIN` | 401 | C | 未登录或登录已过期 | 未携带 token 访问受保护接口；跳登录 |
| 1002 | `TOKEN_EXPIRED` | 401 | C | 登录态已过期，请重新登录 | access token 过期；**静默**用 refresh token 换新并重放一次（仅一次，避免死循环） |
| 1003 | `TOKEN_INVALID` | 401 | C | 登录态无效，请重新登录 | 伪造 / 签名错误 / 已吊销 token；refresh 失败时跳登录 |
| 1004 | `NO_AUTH` | 403 | D | 无操作权限 | 已登录但 RBAC 无权限点 / 数据范围不足；提示无权限**不跳登录** |
| 1005 | `ACCOUNT_LOCKED` | 403 | D | 账号已锁定，请联系管理员 | 多次输错密码等触发锁定；提示联系管理员 |
| 1006 | `ACCOUNT_DISABLED` | 403 | D | 账号已被禁用，请联系管理员 | 账号被停用 / 冻结；提示联系管理员 |
| 1007 | `BAD_CREDENTIALS` | 401 | C | 账号或密码错误 | 登录鉴权失败（不区分“账号不存在”与“密码错误”）；清空密码框 |
| 1008 | `GRANT_ALREADY_ACTIVE` | 200 | B | 你已拥有该资源的有效授权 | 申请冲突校验命中：同资源已有生效授权；**流程提示码**，`data` 附现有授权信息，前端引导直接访问 |
| 1009 | `APPLICATION_DUPLICATE` | 200 | B | 您已有进行中的申请，请勿重复提交 | 申请冲突校验命中：同资源已有在审申请；**流程提示码**，`data` 附在审申请单 ID，前端跳转待办 |
| 1010 | `REASSIGN_INVALID` | 400 | E | 转审目标审批人无效或无权审批该资源 | 审批转审时目标审批人不存在 / 无权审批该资源；提示后重新选择审批人 |

| --- | --- | --- | --- | --- | --- |

### 📁 4xxx：文件 / 传输

#### ⬆️ 上传链路：秒传 / 分片 / 完整性（4001~4003）

| code | 枚举名 | HTTP | 策略 | 中文提示 | 触发场景 / 前端行为 |
| --- | --- | --- | --- | --- | --- |
| 4001 | `INSTANT_UPLOAD_MISS` | 200 | B | 秒传未命中，请按分片上传 | 预检时服务端无相同 SHA-256 文件；**分支码**：`data` 附 `uploadId` 等上传票据，进入分片上传流程 |
| 4002 | `CHUNK_MISSING` | 200 | B | 分片缺失，请按服务端清单续传 | 续传 / 合并前发现缺片；**分支码**：`data` 附缺失分片清单，前端只传缺失片 |
| 4003 | `FILE_INTEGRITY_ERROR` | 409 | F | 文件完整性校验失败，请重新上传 | 重组后 SHA-256 与客户端上报不一致 / 分片不完整；**必须重新上传**，不可续传 |

#### 🗂️ 文件通用（4005~4009）

| code | 枚举名 | HTTP | 策略 | 中文提示 | 触发场景 / 前端行为 |
| --- | --- | --- | --- | --- | --- |
| 4005 | `FILE_NOT_FOUND` | 404 | E | 文件不存在或已被删除 | 详情 / 下载 / 恢复目标不存在；提示后刷新列表 |
| 4006 | `FILE_TOO_LARGE` | 413 | E | 文件大小超出限制 | 超过单文件上限（默认 10 GiB）；上传前本地预检，**不可重试**（换文件或放弃） |
| 4007 | `FILE_TYPE_NOT_ALLOWED` | 415 | E | 文件类型不允许 | 扩展名 / MIME 命中黑名单；上传前本地预检，**不可重试** |
| 4008 | `FILE_UPLOAD_FAIL` | 400 | E | 文件上传失败，请稍后重试 | 分片落盘 / 存储异常；**可安全重试**（已传分片保留，走 4002 续传） |
| 4009 | `FILE_DOWNLOAD_FAIL` | 400 | E | 文件下载失败，请稍后重试 | 读取 / 流式输出异常；**可安全重试**（下载幂等，支持 Range） |

#### 🔗 外发分享（4004 / 4010~4012）

| --- | --- | --- | --- | --- | --- |

## 🔁 四、重试语义（同一策略内的差异说明）

| 语义 | 错误码 | 说明 |
| --- | --- | --- |
| **可安全重试（幂等）** | 4008、4009、4103、5001（仅幂等接口） | 4008 重试前应先查已传分片清单（4002）；4103 重试须退避并降低并发 |
| **仅一次重放** | 1002 | 静默 refresh 后重放原请求**一次**；再次失败即跳登录，禁止循环 |
| **须先刷新状态** | 4102、4004、4012 | 重放必失败，须重新拉取任务 / 链接状态 |
| **须重新发起流程** | 4003 | 分片完整性已破坏，必须重新上传（可复用秒传预检） |
| **不可重试** | 4006、4007、1004、1005、1006、4012、4040 | 请求本身或主体状态不满足前置条件，重试无意义 |

## 📣 五、服务端副作用注明

> 部分错误码在返回的同时会触发服务端副作用，前端与测试需知悉（不因「只是个错误码」而遗漏断言）。

| 错误码 | 副作用 | 依据 |
| --- | --- | --- |
| 4010 → 4011 | 提取码错误计数 +1，连续 5 次后链接锁定 30 min | PRD §6 外发链接规则 |
| 4011 | 站内通知链接创建者 | PRD US-03 / US-08 |
| 4004 | 站内通知链接创建者（失效告知） | PRD US-03 / US-08 |
| 1005 | 登录失败计数累加，达阈值锁定账号 | 红队 [D-03] 登录防爆破 |
| 1006 | 令牌立即吊销（≤2 min 生效） | PRD US-04 / §7 |

> ℹ️ **审计不由错误码决定**：是否落审计事件取决于业务动作（PRD §3 US-06 清单），
> 由 Service 层显式写入；错误码仅用于表达对外结果。
