## 6. CI 安全扫描卡点

```bash
# 2) 前端生产依赖漏洞：high 即失败（dev 依赖不卡，属噪声）

# 3) 历史提交中的密钥：检出即失败
gitleaks detect --config .gitleaks.toml --redact --exit-code 1
```

⚠️ **两个必须知道的前提**：① 该 job 只在 **GitHub 镜像仓库**生效，主仓库 Gitee **无任何 CI 配置**，
